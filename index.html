Academic OS Backup

This is a personal, single-user command-line tool. It backs up a local SQLite database and course files from one person's own computer to that same person's own Google Drive, using the Google Drive API with the restrictive drive.file scope — it can only see files it creates itself, nothing else in the account.

It is not distributed and has no users besides its developer.
