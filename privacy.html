Privacy Policy

Effective: September 2026

What this is

Academic OS Backup is a personal command-line tool with exactly one user: its developer. It is not distributed or offered to anyone else.

What Google data it accesses

It requests the Google Drive API scope drive.file, which grants access only to files and folders the tool itself creates in the user's Google Drive. It cannot see, read, or modify any other file in the account.

How the data is used

The tool uploads the user's own backup files — a compressed database snapshot and a git history bundle, both produced on the user's own computer — to a folder it creates in the user's own Drive, so the user can retrieve them later.

Who the data is shared with

No one. Data is never shared, sold, or disclosed to any third party. It is not used for advertising, and it is not used to train any machine learning or AI model.

Retention and deletion

Uploaded files remain in the user's Drive until the user deletes them directly. Revoking the app's access at myaccount.google.com/permissions immediately and permanently ends its ability to read or write anything.

Security

Authentication uses standard OAuth 2.0. Credentials are stored locally on the user's own machine and are never transmitted anywhere except directly to Google's own APIs.
